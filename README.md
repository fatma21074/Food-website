# 🍔 Food Website

A modern and responsive **Food Website** that displays meals dynamically using a public food API, allowing users to browse meals by category and view detailed information with a smooth and engaging user experience.

---

## 📌 Features

- 🍽️ Browse meals by category
- 🔍 Search for meals in real-time
- 🖼️ Meal cards with hover effects and animations
- 🧾 Meal details displayed in a Bootstrap modal
- ⏳ Loading spinner while fetching data
- 📱 Fully responsive design (Desktop & Mobile)
- 🌐 API integration with CORS handling

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Bootstrap 5**
- **JavaScript (ES6)**
- **Public Food API**
- **AllOrigins CORS Proxy**
